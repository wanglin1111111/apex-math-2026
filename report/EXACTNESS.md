# 算法精确性说明（exactness of `exact_patterns`）

本文件证明 `star.py` 里 `exact_patterns` 对 Experiment 2 家族是**精确**的：它返回
的集合 `P_θ(S) = { θ|_{u+S} : u ∈ Z² }` 恰为全集，既不漏也不多。这是支撑投稿核心主张
「8,000 项窗口检查、0 违例」的数学依据。

三条引理各自独立可核，最后一条（完备性）由 `proof_check_exactness.py` 用可回归
属性锁住。

---

## 记号（与论文 / submission.md 一致）

-   `p` 素，`v_1,…,v_m ∈ Z²` 两两线性无关（本家族 m=2，下同但记号保留 m）。
-   `π_i(z) = det(v_i, z)`；`θ(z) = Σ_i w_i(π_i(z)) (mod p)`。
-   每个 `w_i : Z → F_p` 在窗口 `[a_i, a_i+L_i)` 外为常数 `c_i`，窗内取任意值。
-   `P_θ(S) = { (θ(u+s))_{s∈S} : u ∈ Z² }`，`S` 为格点凸集。

---

## 引理 1（降维：模式只依赖 `t`，不依赖 `u`）

**命题。** 对任意 `u ∈ Z²`，令 `t_i = π_i(u)`。则

$$\theta(u+s) \;=\; \sum_{i} w_i\bigl(t_i + \pi_i(s)\bigr) \pmod p,$$

即模式 `θ|_{u+S}` 是 `t=(t_1,…,t_m)` 的函数，与 `u` 的具体分量无关。

**证明。** 由行列式的双线性：

$$\pi_i(u+s) \;=\; \det(v_i, u+s) \;=\; \det(v_i,u)+\det(v_i,s) \;=\; t_i+\pi_i(s).$$

代入 `θ` 的定义即得。∎

**推论（关键）。** `P_θ(S)` 由映射 `t ↦ (Σ_i w_i(t_i+π_i(s)))_{s∈S}` 在**合法的**
`t ∈ Image(u ↦ (π_1(u),…,π_m(u)))` 上的像完全决定。枚举时只需遍历这个像的每个等价类，
而无需遍历 `u` 本身。

---

## 引理 2（有限性：模式集有限）

**命题。** `P_θ(S)` 是有限集。

**证明。** 由引理 1，模式是 `t` 的函数。又每个 `w_i` 是周期函数：在一个完整周期
（长度由 `v_i` 的 primitive 性给出）之外重复，且在窗口 `[a_i, a_i+L_i)` 外为常数。
故 `θ(t)` 作为 `t ∈ Z^m` 的函数，是一个**周期函数**（每个坐标方向都有周期）。周期
函数的像（在整数格点上）是有限的。∎

**补充（数值界可用）。** 每次 `w_i(t_i)` 改变取值，当且仅当 `t_i` 跨过窗口端点的
某个平移：`t_i + π_i(s) ∈ {a_i, a_i+L_i}` 对某个 `s ∈ S`。于是「`t` 的各个临界值」
构成的有限集合是

$$B_i \;=\; \bigl\{\, a_i - \pi_i(s),\; a_i+L_i-\pi_i(s) \;:\; s\in S \,\bigr\}.$$

只要 `t_i` 落在某个「临界带」之外，`w_i(t_i+π_i(s))` 就与 `t_i` 无关，进而不改变
模式。这给出代码里 `ranges` 的构造依据：`lo = min B_i − 1`，`hi = max B_i + 1`。

---

## 引理 3（完备性：padding 一个基本域即够）

**命题。** 取 `ρ = max_{i<j} |det(v_i, v_j)|`（即代码里的 `padding` 默认值）。若在
引理 2 的临界带 `[lo−ρ, hi+ρ]` 上枚举 `t`，则每个合法 `t` 的等价类至少被覆盖一次，
从而 `exact_patterns` 返回精确全集。

**论证。** 令格子

$$\Lambda \;=\; \bigl\{\, (\pi_1(u),\dots,\pi_m(u)) \;:\; u \in Z^2 \,\bigr\} \;\subset\; Z^m.$$

两个 `t, t′` 产生相同模式当且仅当 `t−t′ ∈ Λ`（因为 `w_i` 只依赖 `t_i mod` 周期，而
周期正是由 `π_i` 在 `u` 方向的线性性给出）。所以等价类是 `Z^m / Λ` 的陪集，枚举只需
覆盖每个陪集的至少一个代表。

下面把「覆盖充分性」拆成**可证明的部分**与**经验充分性部分**，不混淆两者。

**（可证明）像格基本域面积恰为 `|det(v_1,v_2)|`。** 对 m=2，`Λ` 由两个生成元

$$g_1 = (\det(v_1,e_1),\det(v_2,e_1)),\qquad g_2 = (\det(v_1,e_2),\det(v_2,e_2))$$

张成（`e_1=(1,0), e_2=(0,1)`）。直接计算其基本平行四边形面积：

$$\bigl|\det(g_1,g_2)\bigr| = \bigl|\det(v_1,v_2)\bigr|.$$

（成立性已由 `proof_check_exactness.py` 在全部方向对上逐一断言。）

**（可证明）每个方向都能独立平移 1 个单位。** 对任意 primitive `v_i`，存在 `u`
使 `det(v_i,u)=1`（本家族 `v_i` 均 primitive；已逐向断言）。因此当某一坐标 `π_i` 需要
移动 1 时，总能找到对应的 `u`，而不受其它坐标约束——这是枚举盒能「按坐标分头」补代
表的依据。

**（经验充分性）`max|det|` 作为代表平移界。** 基本域面积 = `|det|` 给出「等价类
的稠密度」，直觉上代表之间的间距不超过基本域的坐标直径；在本仓库全部方向对上，约化
基的坐标直径实测 ≤ `|det|`。但本仓库**不把「直径 ≤ det」宣称为形式化定理**，而是用
以下两条独立的、可回归的机器证据锁定完备性：

1.  `proof_check_exactness.py` 断言 **padding 加倍后模式集不变**（fixpoint）：若 `max|det|`
    不足以覆盖某等价类，加倍必然引入新模式；实测 1,200 个（配置×窗口）对均无新
    模式。
2.  上述 1,200 对覆盖了比论文附录 C.2 更宽的方向集（含 `(2,3)`、`(3,2)`、`(5,2)`
    等大行列式方向）与更大窗口（6×6、8×5），对 `max|det|` 上界构成更严的压力
    测试。

证据合起来表明：在 Experiment 2 家族的取值范围内，`padding = max|det|` 已充分，
枚举盒覆盖每一等价类，无遗漏。∎

**备注（为什么是 `ρ` 而非经验值；以及诚实边界）。** 之前发现的「少算 3 个模式」的
bug，正是 padding 取 1（单一远代表）不足以覆盖像格基本域所致。取 `ρ = max|det|` 后，
实测定点性质成立。本文件明确区分：**下限与稠密度是定理，`max|det|` 的充分性是
「定理 + 可回归机器验证」共同支撑的经验结论**，不伪装成纯形式化证明。

---

## 三条引理对「精确」的完整含义

| 引理 | 作用 | 排除的错误 |
|---|---|---|
| 1 降维 | 只需遍历 `t`，不必遍历 `u` | 遍历 `u` 的漏项 |
| 2 有限性 | 枚举盒有限 | 死循环 / 无限集 |
| 3 完备性 | padding=ρ 覆盖所有等价类 | 少算远代表（已发生的 bug） |

三者合起来：枚举盒是有限的（引理 2），覆盖每个等价类（引理 3），且每个 `t` 映射到
唯一模式（引理 1）→ 返回精确全集，无漏无重。
