C.1. Method.
• Configurations. Each component is specified by a primitive direction vi, a tangential
period ki, an arbitrary value table on the transition strip [ℓi, ri], and left and right tails
Li, Ri given, in the basis (vi, ui) of §0.3, as doubly periodic tables in (t mod a, s mod ki).
Axioms (S1) and (S3) hold by construction. Axiom (S2) is decided exactly: Fi is doubly
periodic if and only if it coincides with the global extension of its left tail (a doubly
periodic function vanishing on a half-plane vanishes identically), and that coincidence is
tested on the strip and on one full period beyond it. With M the least common multiple
of all the kj and of all the tail period indices, the lattice Γ of §0.3 contains MZ2, and the
program uses Hi = Mkivi; by Remark 1.4 this choice, which need not be the minimal
one, does not affect the Case A/Case B decision, and it does not affect Λi either, since
refining the period only adds zero Fourier coefficients.
• Pattern counts. The S-patterns are enumerated at all anchors of the square box of radius
R = 90 and again of radius R = 180. The entries labelled Pθ(S) below are these observed
counts, hence lower bounds for the global complexity. The two counts agreed on every
reported window, but this agreement alone does not certify exhaustiveness: that would
require covering the strip crossings and all periodic phase classes outside them, with the
window offsets included.
• Deciding the case. DIa is computed on the box of radius 40 from the formal expansion
(0.1). A non-zero value certifies Case A; an all-zero result only suggests Case B unless
the box covers the support. For the reported configurations, the case assignments were
additionally confirmed on boxes containing all pairwise intersections of the strips

expand the four-point template {z, z + H1, z + H2, z + H1 + H2} at an anchor z: δ1 is constant

occurs only for | det | ≥2. The sample of Experiment 2 was generated at random and then sorted
by the numerical test; the criterion explains why Case B appeared only on direction pairs with
| det | ≥2.
C.3. A counterexample to the generalisation of Lemma 3.1. (lemma31.py.) Take p = 2,
m = 3, v1 = (1, 0), v2 = (0, −1), v3 = (1, −1). Tails: L1 = 0 and R1 = ⊮[x even]; L2 = L3 = 0
and R2 = R3 = ⊮[3 | x]; the transition strip of each component is constant 1, of width 1. Here
π2(v1) = π3(v1) = 1 > 0, so B+

1 = L2 + L3 = 0, and the program
computes Λ1 = {±1} (with κ1 = 12 and frequencies {0, 6}), so that A1(T v1) = T 2v1 −1.
• For the pairs of realised sectors adjacent along the rays ±v1, namely (R1, R2, R3) with
(L1, R2, R3) and (R1, L2, L3) with (L1, L2, L3): the difference after applying A1(T v1) is
0, up to a floating-point error of 1.3 · 10−16, for both colours.
• For the mixed choice (R1, R2, L3) against (L1, R2, L3) — here B = R2 + L3 = ⊮[3 | x],
and the sign vector (+, +, −) corresponds to the cone {y > 0, x > 0, x + y < 0} = ∅,
which is not realised: the difference after applying A1(T v1) has maximum absolute value
2.
By hand: along the x-direction, ∆1 = ⊮[R1 + B = 1] −⊮[L1 + B = 1] takes the values
